# Known-Case Fixtures

Known-case fixtures are frozen in Stage 3 before judged builders run.

Each fixture should include:

- source inputs;
- expected analytical judgments;
- expected final action where applicable;
- rationale;
- and the exact Stage 3 rule being tested.

Do not rewrite a fixture after a builder fails it. A failed fixture is evidence against the implementation until the discrepancy is understood and resolved.
